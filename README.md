# adambrzezinski.com

Personal academic website. Plain HTML/CSS/JS — no build step.

- `index.html` — all content (bio, papers, contact)
- `styles.css` — design
- `script.js` — scrollspy for the nav
- `assets/profile.jpg` — photo
- `CNAME` — tells GitHub Pages the custom domain

## Editing

Edit `index.html` directly (each paper is one `<article class="paper">` block —
copy-paste one to add a paper), commit, push. GitHub Pages redeploys automatically
within a minute.

## Preview locally

Just open `index.html` in a browser.
